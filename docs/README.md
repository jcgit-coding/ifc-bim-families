# Project documentation

This folder keeps everything needed to audit the project: what was asked, what was decided and why,
how the work is organised and which rules apply. The root `README.md` only introduces the project.

| Document | Purpose |
| --- | --- |
| [requirements.md](requirements.md) | Requirements as stated by the project owner, with their status |
| [plan.md](plan.md) | Architecture and phased implementation plan |
| [decisions.md](decisions.md) | Decision log (what, why, alternatives, date) |
| [design.md](design.md) | Interface design principles, tokens and behaviour |
| [standards.md](standards.md) | Coding, naming and quality rules (enforced by `npm run check`) |
| [adding-a-template.md](adding-a-template.md) | How to add a new family |
| [roadmap.md](roadmap.md) | Done and next steps |

Keep these documents in English and update them in the same change that alters the behaviour they describe.
